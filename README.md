# 故宮南院行程

**網站連結：<https://sesame55.github.io/gogogoNS/>**

故宮南院（嘉義太保）一日遊的旅遊攻略網站。以手機瀏覽為主，水墨風格設計，支援淺色／深色模式。

## 頁面內容

| 分頁 | 內容 |
| --- | --- |
| 總覽 | 南院建築與展覽簡介、出發前須知 |
| 行程 | 一日遊、二日遊時間表，下雨與季節建議，周邊順遊景點（附開車時間與照片） |
| 看展 | 目前展覽、建議參觀動線、園區地圖（拍照點、公共藝術、停車場、接駁站） |
| 交通 | 開車與停車場、高鐵免費接駁車與 BRT 7212 時刻表、其他公車 |
| 美食 | 南院周邊、太保、朴子、嘉義市的店家；依台灣時間顯示是否營業中；地圖上有距離圈 |
| 準備 | 出發前檢查清單（勾選狀態會保存在瀏覽器） |

## 注意事項

- 展覽、開放時間與接駁車時刻以[故宮南院官網](https://south.npm.gov.tw/)公告為準，網站上有標示資料確認日期。
- 店家「營業中」是依整理到的營業時間推算，國定假日與臨時公休無法反映，出發前建議先電話確認。
- 距離圈是距南院的直線距離；開車距離與時間為估算，實際依路況而定。

## 檔案結構

```
index.html      頁面內容
css/style.css   樣式
js/app.js       分頁切換、地圖、營業狀態等互動
js/shops.js     美食店家資料（營業時間、座標、距離）
js/spots.js     園區地圖的景點資料
img/            展覽圖片
backup/         雜貨風格的備用版本
```

純靜態網站，不需要安裝或建置。本機預覽時請在資料夾內執行 `python -m http.server`，再打開 <http://localhost:8000>；直接雙擊 `index.html` 的話，OpenStreetMap 地圖不會載入。
